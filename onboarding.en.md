# Study Companion: Your First Study Session

This guide walks you through a real study session: add material, get an explanation, practise, build memory, and review what you accomplished. You do not need to understand every setting before you begin.

## When you open it for the first time

1. Choose your learning stage. It keeps the knowledge map and practice questions within a useful range. You can change it later under Advanced Settings > Study.
2. Look at the mode buttons at the top. Choose Companion if you are unsure.
3. If explanations are not ready, open Advanced Settings > Study and check Text and document model. Follow the on-screen link to N.E.K.O model settings if needed.

OCR is optional. You can still begin by pasting text or importing a file when OCR is unavailable.

## The six study areas

- Study: add text, questions, images, or documents and get explanations.
- Practice: generate questions from the study history you have built and check your answers.
- Memory: make cards and review them when they are due.
- Knowledge: explore relationships between topics and choose what to practise next.
- Focus: set today's goal, use the focus timer, and check in.
- Notebook: organise, search, edit, and export your notes.

Select an area from the navigation. Use Overview in the upper-left corner to return to your current status and shortcuts.

## 1. Choose how you want to study

- Companion: best for a quick explanation while reading or solving a problem.
- Interactive: best when you want more questions and prompts that make you think actively.
- Teaching: best for learning from the basics with a step-by-step explanation and guided practice.

You can change modes at any time with the three buttons at the top. Switching modes does not erase your saved work.

## 2. Add learning material

Open Study and choose any of these methods:

- Paste a concept, problem, or passage into the input area.
- Select Import file, then choose a TXT, Markdown, PDF, or DOCX file. You can also drag a file onto the page.
- Select OCR at the top. After the countdown, switch to the page containing the material and drag over the area you want to read.
- If image understanding is enabled, paste a JPG or PNG image directly.

OCR only extracts text from the selected screen area. It does not automatically detect or split questions. Check the text in the input area after capture, correct anything that was misread, and then select Explain.

For an imported document, you can choose its type and add an analysis focus such as “extract exam topics” or “map the character relationships.” Select Analyze document when ready. A scanned PDF is converted to text first when OCR is available. Progress is shown on the page, and long documents may take more time.

Study Companion does not retain the original imported file. Text or images that need analysis are handled by the model you selected in N.E.K.O.

## 3. Move from explanation to practice

After selecting Explain, read the response and make sure the central idea is clear. Then open Practice:

1. Review the selection reason and practice scope.
2. Select Generate Practice.
3. Use the hint if needed, then enter your answer.
4. Select Evaluate Answer to see what you covered, what you missed, and what to do next.

Practice selects questions from weak topics, due reviews, and your existing study history. It does not use temporary text in the input area or OCR capture as a direct question source. If you see “Not enough study records yet,” complete a few explanations, save or review some cards, or choose a topic from Knowledge as the practice scope.

Wrong and partly correct answers can return in later practice. Select Summarize Session after a round to review the result.

## 4. Turn important points into memory cards

Open Memory:

1. Put a question or cue on the front and the answer or recall target on the back.
2. Choose a card type and deck. On your first card, create a deck or use the default one.
3. Select Save Card.

When a due card appears, try to recall it before revealing the answer. Then choose Again, Hard, Good, or Easy honestly. Your choice controls when the card returns, so there is no benefit in marking everything Easy.

## 5. Keep a steady rhythm with goals and focus

Open Focus to use the timer. Today's goal is under Advanced Settings > Habit > Edit Daily Goal:

- Card goals work well for vocabulary, formulas, and short facts.
- Minute goals work well for reading, writing, or focused problem solving.
- Attempt goals work well for drills and repeated practice.

Set a goal, return to Focus, and start the timer. During breaks, follow the controls to continue, pause, or skip. When you finish, use the Check-in shortcut on Overview to record the day. Overview also shows the current duration, goal progress, and number of due reviews.

## 6. Use the knowledge map to choose your next step

Knowledge organises saved topics, relationships, and mastery into a map. Select a topic to make it your practice scope, then return to Practice to generate a matching question.

An empty map is normal at the beginning. Topics appear as you complete more explanations, answers, and reviews. When you have finished a selected scope, clear it to return to adaptive selection.

## 7. Organise notes and review the session

In Notebook, you can create notebooks and notes, add tags, search, and use AI Expand to develop a draft. To export:

1. Open Advanced Settings > Data.
2. Enable Note export and select Save Settings.
3. Select Export Notes and choose one of the formats shown. You can also select notes in Notebook and export only those items.

Session Summary on the same settings page gives you a quick view of completed work, memory reviews, and anything still waiting before you finish.

## If something is not working

- No explanation appears: open Advanced Settings > Study and confirm that Text and document model is ready. Otherwise, follow the on-screen link to N.E.K.O model settings.
- OCR is unavailable: under Advanced Settings > Study > OCR, make sure it is enabled and follow the action beside its status. You can paste text or import a file in the meantime.
- OCR text is inaccurate: select a smaller area, avoid busy backgrounds, and correct the input text before asking for an explanation.
- Practice has no question: build some explanation, card, or review history, or select a scope in Knowledge, then select Generate Practice again.
- Knowledge is empty: complete a few explanations, answers, or reviews and return later.
- Export is unavailable: make sure Note export is enabled and saved under Advanced Settings > Data, and that you have notes to export.
- Document analysis is taking a long time: stay on the page while progress continues. If the material is too long, remove it, shorten it, and import it again.

## Three useful routes

- Understand one problem: Study > paste the problem > Explain > Practice > Evaluate Answer.
- Review a chapter: Study > import notes > Analyze document > Knowledge > choose a weak topic > Practice.
- Build long-term memory: Memory > create or import cards > Focus > Due Reviews > Session Summary.
