# v0.3.0 发布说明

## 发布定位

本版本收口认知引擎 V3/V4 的工程实现，并保留所有认知行为默认关闭。
它不宣称教学效果或记忆提升，也不把知识副本原型接入正式学习入口。

## 主要变化

- 增加默认关闭的策略归因、受控轮换和证据门控个性化能力。
- 增加连续失败停止、用户停止、并发交付复核和运行状态入口。
- 教学覆盖扩展到知识图谱主题的确定性 probe/repair/transfer 蓝图。
- 保留知识副本 `knowledge_dungeon/` 原型，但它仍是独立演示模块。
- 认知失败继续回退普通学习流程，不影响 FSRS、Mastery、课程进度和错题状态。

## 默认边界

`projection`、认知读取、意图、UI、retention、策略归因、轮换和个性化开关均保持关闭；发布版本集仍为 `cognitive-v2.1-1`。启用任何实验能力都需要显式配置并单独验证。

## 验证范围

本版本包含合成数据工程验收和定向回归；统一安装后的真实环境验证及真人教学效果评估不包含在本次发布结论中。
