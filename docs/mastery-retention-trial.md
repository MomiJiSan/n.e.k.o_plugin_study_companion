# 知识卡成长与遗忘首版试行

本版将伴学有效作答投影为知识卡掌握度，通过本地桥提供给游戏。参数版本为 `mastery-retention-trial-1`；7 天是工程试行初值，0.1% 是产品归零门槛，均不代表经过个人数据验证的记忆常数。本规则不是标准 FSRS 或已训练 HLR。

## 伴学权威数据

最近有效评估的基准掌握度乘以 `2 ** (-经过天数 / 半衰期)`，只应用一次时间衰减。低于 0.001 归零，等于 0.001 保留；达到 0.01 获得卡牌，已有卡低于获取门槛仍保留，直到归零。销毁与重新获取使用持久化代次，旧升级不能转移到新代次。

无提示答对按 `h * (1 + c*w)` 更新半衰期，明确答错按 `h * (1 - 0.5*c*w)` 更新，其中 `w = 1 - 2 ** (-Δ/h)`。部分作答或提示后作答保留半衰期。置信度为评判可靠性，缺失时不补为 1；缺少可靠来源、失败评判不能冒充答错。有效部分作答可以形成新锚点，但不能仅刷新时间而恢复历史高分。

新投影使用按题目内容、练习会话与时间关联去重的近期答题证据，采用独立命名的试行基准估计。错误后的基准不高于答题前已衰减的掌握度。重复 attempt 不重复消费时间间隔；事务提交同时保存基准、半衰期、锚点及代次事件。自评、阅读和游戏操作不写入这条学习锚点。

首次读取可从升级前的 V1 历史快照迁移，保留原评估时间，不叠加 V2 的日期衰减。未评估使用空掌握度；损坏数据与读取错误不能作为归零依据。试行参数变化需要明确迁移，不能静默追溯修改已确认代次。

## 游戏接口与会话

插件启动时将 `KnowledgeTracker.get_learning_card_snapshot` 传给 `KnowledgeDungeonPrivateBridge`。快照包含数据集身份、版本、时间和所有学科的知识点掌握度、持有状态与代次。收藏覆盖已掌握的各学科知识点；地图内容仍受现有场景支持范围限制。

私有连接认证继续使用 v1；真实学习领域请求使用 v2：

| 路由 | 用途 |
| --- | --- |
| `/v2/bootstrap` | 能力信息 |
| `/v2/game-sessions/begin` | 捕获或恢复整次游戏快照 |
| `/v2/game-sessions/select` | 从冻结收藏选择出战卡 |
| `/v2/runs/create` | 创建远征 |
| `/v2/runs/get` | 恢复存档并按新会话协调 |
| `/v2/runs/action` | 提交带版本和请求身份的动作 |

游戏进程生成会话身份。营地、下一次远征、窗口重载和断线重连不刷新掌握度；完整退出后重开才取得新快照。服务器保存快照以支持伴学桥重启，旧会话不能覆盖新会话。学习不可用时返回错误，不用模拟收藏或零掌握度替代。

营地最多选择 12 张卡，包含固定 1 点伤害的“红葉的怜悯”。知识卡基础伤害为 `max(1, 6*掌握度)`，例如 20% 为 1.2；战斗场景的既有修正另行应用。归零卡不能因最低伤害保留。游戏战斗不发放学习卡或恢复掌握度。

新会话继续旧存档时，仅保留同数据集、同代次卡，更新其掌握度；过期代次从相关牌堆移除，不重洗牌、不补抽、不用新代次替换。已结算的生命、能量、进度和奖励保留。数据集不匹配应阻止协调，不能当作所有卡遗忘。

## 验证与后续校准

`tests/test_mastery_retention_bridge_flow.py` 使用真实 StudyStore、KnowledgeTracker 与经过认证的 HTTP 桥，验证学习提交、会话冻结、七天衰减、销毁和新代次获取。算法、持久化、桥会话和客户端各有边界及失败恢复测试。

数学与软件回归通过不代表实际学习效果已被验证。后续按时间划分真实间隔测验数据，比较预测与表现，并按学科、题型及提示状态观察误差；校准在伴学侧进行。
